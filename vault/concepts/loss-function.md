# Loss Function（損失函數）

## 中文速解
量化模型預測結果與真實標籤差距、供最佳化更新參數的目標函數。

## Explanation
A loss function measures the discrepancy between predicted outputs and ground-truth targets on training samples. Examples include the multi-class SVM loss (hinge loss) and cross-entropy loss (Softmax). The overall objective guides parameter updates during optimization.
