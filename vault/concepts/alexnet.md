# AlexNet（AlexNet 架構）

## 中文速解
2012 年帶動深度學習浪潮、首度採用 ReLU 與 Dropout 的經典 CNN。

## Explanation
AlexNet is a landmark 8-layer convolutional neural network (5 convolutional layers and 3 fully-connected layers) that won the ImageNet Large Scale Visual Recognition Challenge in 2012. It demonstrated the practical power of GPUs, ReLU activation functions, and Dropout regularization.
