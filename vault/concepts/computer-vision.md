# Computer Vision（電腦視覺）

## 中文速解
讓電腦從數位影像或視訊中獲取高層次理解與特徵的領域。

## Explanation
Computer Vision involves developing algorithms that extract visual representations and understand semantic structures from images or video streams. Key challenges include viewpoint variations, illumination changes, deformation, occlusion, and the semantic gap between raw pixel values and real-world concepts.
