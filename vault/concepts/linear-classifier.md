# Linear Classifier（線性分類器）

## 中文速解
透過權重矩陣與輸入特徵線性組合計算各類別分數的基礎模型。

## Explanation
A linear classifier computes output class scores via a linear function $f(x, W, b) = Wx + b$, where $W$ is the weight matrix and $b$ is the bias vector. It can be interpreted as learning visual templates for each category, or geometrically as dividing the feature space with linear hyperplanes.
