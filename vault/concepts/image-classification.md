# Image Classification（影像分類）

## 中文速解
將輸入影像指派至預先定義的類別標籤的基礎電腦視覺任務。

## Explanation
Image classification is a fundamental task where a model takes an input image and predicts a categorical label from a pre-defined set of classes. Common methods range from data-driven nearest neighbor search to parametric linear classifiers and deep convolutional neural networks.
