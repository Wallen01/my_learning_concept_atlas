# Attention（注意力機制）

## 中文速解
依當下任務對不同輸入資訊分配不同權重，讓模型聚焦較相關內容的機制。

## Explanation
Attention computes weighted combinations of representations. The weights depend on relevance, enabling a model to access different parts of an input instead of compressing all information into one fixed state.
