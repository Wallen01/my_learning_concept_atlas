# Optimization（最佳化）

## 中文速解
透過數值迭代反覆更新模型參數以最小化損失函數的搜尋過程。

## Explanation
Optimization searches for parameter values that minimize an objective loss function. In deep learning, analytic solutions are unavailable, so iterative numerical algorithms such as gradient descent, momentum methods, and adaptive learning rate optimizers are used to traverse the loss landscape.
