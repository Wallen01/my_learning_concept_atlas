# Convolutional Neural Network（卷積神經網路）

## 中文速解
專為格狀資料設計的神經網路，常用卷積層從影像中擷取局部到高階特徵。

## Explanation
A Convolutional Neural Network (CNN) applies learnable filters across an input such as an image. Local receptive fields and shared weights make it well suited to spatial patterns.
