# Recurrent Neural Network（循環神經網路）

## 中文速解
透過隱藏狀態保留先前資訊、逐步處理序列資料的神經網路。

## Explanation
An RNN reuses a transition function at each time step and carries a hidden state forward. This lets the model represent order-dependent information in a sequence.
