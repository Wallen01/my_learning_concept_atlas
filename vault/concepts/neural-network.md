# Neural Network（神經網路）

## 中文速解
由多個可學習層組成的模型，透過調整參數把輸入資料轉成預測結果。

## Explanation
Neural network 由一系列層組成；每一層對前一層輸出套用可學習的轉換與 activation function。多層結構能表示比單一線性模型更複雜的關係。
