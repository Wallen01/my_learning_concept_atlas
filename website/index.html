CONCEPTS

Concept map

Neural Network 神經網路

由多個可學習層組成的模型，透過調整參數將輸入轉為預測。

Related: Backpropagation · CNN · RNN

Backpropagation 反向傳播

從誤差往回計算各層參數梯度，使模型得以更新權重。

Related: Neural Network

Convolutional Neural Network 卷積神經網路

以卷積層擷取影像局部到高階特徵的神經網路。

Related: Neural Network

Recurrent Neural Network 循環神經網路

以隱藏狀態保留先前資訊、逐步處理序列資料的模型。

Related: Attention

Attention 注意力機制

依任務對輸入資訊分配權重，讓模型聚焦相關內容。

Related: Transformer · RNN

Transformer 轉換器架構

以注意力為核心、能平行處理序列關係的模型架構。

Related: Attention
